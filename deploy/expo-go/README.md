# Expo Go preview retired

The `go.luche.ai` preview and its automatic deployer were retired on
2026-11-09. Luche requires native modules that Expo Go cannot provide.
Use a native development build, TestFlight, or the Android APK.

Pushes no longer deploy an Expo Go preview or send Telegram notifications.
The gateway, Metro service, update timer, and launch QR code were removed.
Operations record: shared vault `wiki/ops-infra/pi/luche.md`.
